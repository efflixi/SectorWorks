read-only is not a promise that every unsupported feature is readable. No admission
check, system metadata or log is removed. No replay/reset/repair, authentication
suffix stripping, host mounting/normalization prerequisite or privilege/ACL
weakening follows from this decision. Formatting and bootability/exact-layout
claims remain separate, unavailable unless independently qualified.
